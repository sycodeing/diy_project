# X 个人消费场景发现（v9）

手动“个人消费场景召回”先查近期送礼与家居个性化讨论，第三页起可查明确买家提问。默认最近 3 天、最多 2 页，可选 3 页覆盖前三组；硬上限 8 页，余额低于 3000 credits 或本轮观察支出达到 2500 credits 即停。控制查询默认关闭。每页原始响应先写本地档案，再按原帖正文和已返回的作者简介判定；不会额外查询作者档案。

`pet-demand-v9-consumer` 把本人当前询价、求推荐、下单选择列为 `explicit_request`；把本人正在选礼、布置家居、考虑宠物照片个性化实物等有行动信号的场景列为 `exploratory`（潜在消费场景）。只有实际提问才记录请求原文，单纯计划不伪造求购句。只晒宠、仅生日/搬家事件、泛愿望、商家广告、已购或已收礼、已完成 DIY 均排除。文本结果保留原文片段、消费/场景/商品/收礼对象证据、排除理由和分类器版本。作者简介出现明确商家销售证据时优先排除；简介为空不能证明非商家。

召回结果仅进 `x_lead_raw_reviews` 待筛表。页面默认显示尚未忽略的潜在场景与明确需求，并提供全部原始帖和排除诊断；旧分类版本的记录不会自动改判。原帖图片只用于理解语境，未核验归属或是否为可用的宠物实拍，不能称为该用户的定制预览。潜在顾客的草稿只能邀请查看自家示例。即使帖子有公开美国位置和图片，`exploratory` 仍不得进入严格 `x_leads`、照片验证、发送队列；旧需求路径只有 `explicit_request` 能继续经过原有严格核验。所有联系仍需人工复核与现有审批。

本地验证：`x-lead-studio/.venv/Scripts/python.exe -m pytest x-lead-studio/tests/test_purchase_intent.py x-lead-studio/tests/test_probe_purchase_recall.py -q`。在线获取需要发现执行器版本至少 1.15.0；本规则发布不会自动刷新旧记录，也不自动启动付费搜索。
