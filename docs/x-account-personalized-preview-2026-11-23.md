# X 账号原创设计预览回复（2026-11-23）

V2 的 `account_product_preview` 现默认从本人已核原帖选择本店原创设计：三款已审的品牌原画随应用打包，明确配色场景可用可复现的几何图案配方；没有可信颜色或主题时只留文字草稿并说明原因，自动图文入队失败。管理员可明确选择纯文字模式，人工上传原创设计保留在高级操作中。现有有效人工图在普通入队时会保留；明确重生成图文才替换。当前文案与程序图由规则生成，**运行时不调用 AI**。设计原画放入真实在售商品模板，预览与 `/g/` 商品链接绑定同一原画，不使用候选账号、原帖或他人的图片作印花。

操作顺序：管理员逐个核对原画、模板渲染图、商品、唯一追踪链接、目标原帖和完整回复文案；在 `/admin/x-auto-posts-v2` 将该账号任务加入待审队列；再对该条任务**单独明确批准**。入待审不等于批准或发送。批准后的任务仍受既有时效、去重、每日额度、账号映射、执行器健康和网络出口约束。旧 `account_product_link` 纯文本模式及 V1 流程继续保留。

Worker 领取图片模式前须更新至 `4.12.0-account-product-preview` 并报告 `account_product_preview_v2` capability。领取数据绑定已批准的文案、唯一 `/g/` 链接、不可变预览图路径、签名 URL 和 SHA-256；worker 下载该图并核对字节哈希后才附图发送。下载或校验失败时任务失败，不降级为纯文本发送。更新 Mac 现有 clone 时先停止原有 worker，检查本地修改、`git pull --ff-only`，再从 `x-lead-studio` 按原方式启动并核对心跳。此次更新不改变 `X_REPLY_EXECUTION_MODE`、发送账号或网络配置，也不自动批准任何任务。

三款品牌原画及哈希清单位于非公开的 `assets/account-designs/v1/`，随两个后台路由打包，不是公开静态 URL。含个人证据的映射、模板渲染样例与 `PROMPTS` 保存在 Git 忽略的 `.data/account-design-samples-20261123/`。离线复核现有 20 条证据：17 条可选原创设计、3 条因缺乏明确设计依据保持纯文字；15 个不同图案与模板组合、5 类程序构图、12 套配色，实际生产草稿须再经服务端校验。共享设计的模板结果可命中私有 Storage 缓存，但每个账号仍有独立文案和追踪链接；同实例并发只渲染一次，跨实例首轮可能重复。
