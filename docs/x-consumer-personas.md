# X 三类个人消费场景待筛

本模式 `consumer_recall` 与原有猫狗严格候选分开。它只读 TwitterAPI.io 的近期原帖，保存每页原始响应到本机归档，再把未曾归档的帖子及证据写入 `x_lead_raw_reviews`。原帖图片仅作语境资料，不证明归属，也不会生成定制预览。原始待筛、文本入选或高复核优先级均不授予联系资格；不会进入 `x_leads`、回复队列或自动发送。

三个画像分别是：有具体收礼对象且礼物尚未完成的 `gift_giver`；对宠物、汽车、原创角色、音乐等兴趣有周边消费或定制行为的 `identity_consumer`；本人筹办团体活动且有未结束节点的 `group_organizer`。普通晒图、生活事件、泛兴趣、商家广告、已经解决的当前需求和自制成品不构成当前顾客线索。历史买周边只证明兴趣，不等于本轮要购买；`current_need=unknown` 应按低优先级核实。`product_fit=verified` 仅指当前文字明确匹配照片枕套，`adjacent`/`unknown` 不表示网站已支持该商品或批量能力。画像证据、商品适配、复核优先级均可在原始待筛页查看；草稿只展示自家实例，须人工审阅。

手动三画像任务使用最近三天的六组短查询，按送礼、兴趣、活动各一组，再各第二组，每组最多一页。完整小批最多六搜索页；余额低于 3000 credits、观察支出达到 2500 credits、来源错误或限流立即停止，不盲重试。开始付费搜索前必须取得生产已联系账号/帖子快照，快照获取失败则停止。任务指标分别报告原始新帖、独立作者、画像作者、已联系排除、搜索页和严格候选零；旧数据不会自动重分类或更改人工状态。

本地验证：`x-lead-studio/.venv/Scripts/python.exe -m pytest x-lead-studio/tests/test_consumer_recall.py -q`。上线后须查看执行器版本至少 1.16.0、无其他运行任务、提供者余额、归档路径、数据库原始行和三个画像的独立作者数。搜索任务只由后台手动触发，不改变旧定时配置。
