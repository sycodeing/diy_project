## 账号页按钮

`/admin/x-accounts` 的“使用绑定代理打开 X 首页（x-use）”使用独立手动助手，不依赖已停的自动 worker 心跳。仅上述固定、启用且绑定配置可用的账号开放；停用账号仍保持暂停。代理及账号映射的既有通过结果标为历史记录，不代表当前会话、出口或登录状态正常。

点击按钮本身表示这次明确请求，无需额外勾选：按原 x-use MCP 浏览器链加载该账号本地 Cookie、使用原绑定代理预检出口并打开 X 首页时间线；不会批准、回复、私信、点赞或发送。该按钮确实会打开 X，不能把它称作仅 IP 检查。没有助手在线、绑定缺失/变化、暂停或会话阻断时拒绝，不直连、不换账号、不恢复自动服务。

## 独立手动助手

`x-lead-studio/run-account-manual.sh` 只启动手动 helper。空闲启动只读取本站后端配置、注册新 boot 并轮询独立请求表；不会读取真实 x-use 账号配置/Cookie，不启动 MCP、浏览器、绑定代理或访问 X。旧 native helper 版本及历史 IP-only 请求不能领取新 x-use 请求。新请求绑定当前 capability、boot、明确 purpose、固定账号和网络版本，过期两分钟或前一启动的请求不执行。

只有用户未来明确点击新按钮，才在原 Python 环境启动受限 x-use MCP：复用本机原兼容 shim、官方 `create_server`、Patchright SessionPool 与原 context 工厂。沿原匿名代理检查核对预期出口，再通过原只读 policy/ready 链打开首页，核对当前可见登录账号。所有原发送、批准、队列、恢复和账号修改工具都从该 MCP 移除，auto-drain 不启动。当前授权的有效 loopback route 仅在固定账号的 ConfigLoader 内存副本同步，不写账号文件、active 或 Cookie。

这与原 x-use 一样是 Cookie 导入的非持久 context，不是标准 Chrome 的长期用户资料目录。手动适配器保留同一 MCP 会话及已有 Pool lease，避免每次请求后关窗和闲置十分钟回收；同账号同绑定的后续请求仅检查本地 transport，不刷新、不导航或新增标签。心跳独立于长开窗请求，只上报缓存状态，不访问 X；浏览器页面自身仍可能产生后台流量。从未尝试启动 MCP 的纯空闲助手，在休眠或断网恢复后可续同一 boot 的本站心跳；后台先令该 boot 旧 pending 请求失效并核对没有已领取/不确定任务，再恢复在线，不重放旧请求。显式 stopped、blocked、closed 或已有会话不自动续期；停止时保留原会话标识。旧助手版本不接收新帖子请求。

取得当前会话身份/出口证据后，后台提供目标链接复制及“在原 x-use 标签打开目标帖子”。帖子按钮使用独立 v3 purpose，只在本助手已持有的同账号同绑定 context 调用原 x-use 的导航方法，不重新导入 Cookie、不新建 context/标签；没有原 client 或窗口归另一进程时明确阻断。首次建立会话仍须用户在账号页明确点击首页按钮。用户核对账号、手动上传图片并发送；助手不替用户点击发送。复制、下载或登记不导航 X，也不关闭会话。图文卡片的“下载商品预览图”提供由原审阅 WebP 派生的 PNG；复制文案不会附图，须本人手动上传。登记只记录用户声明，不能当作平台已核验。

## 数据保护

手动队列、助手状态和开窗请求使用独立表，不进入自动执行器。转换时原18来源仅在事务中复制审阅正文、目标、追踪链接及素材哈希后退出自动队列；原账号、批准、计划和素材保留审计快照。两条已发送/未决历史不转账号、不重发。填写指定账号的结果 URL 后即可点击登记，无需勾选账号或附件声明；登记只记录本人自报，平台结果与附件是否上传均未自动核验。历史 preview_uploaded_by_user 列和值保留，新登记不写该字段；默认 false 仅表示没有附件声明，不表示已经核验上传或确定未上传。

网站发布或助手安装不代表授权代理实际打开 X。本轮实现验收仅使用离线模拟和本站只读状态；真实开窗由用户未来明确操作。

## 更新边界

代码和迁移发布不会热更新已在“停止接收、保留窗口”循环中的旧 Python 进程；该进程没有安全恢复心跳的控制入口。保留原窗口期间不重启助手、不注册新 boot。用户自行关闭旧窗口后，先以本地进程/owner lease 已释放的证据确认会话结束，再以旧 helper_id、boot_id、session_id 的精确条件将后台旧记录标为 stopped/closed（不得清理历史请求或重置去重）；旧 v2 可能不会上报 closed，须保留该核对步骤。随后才更新本机 helper 文件并按新的明确授权启动，启动本身不访问 X。新会话必须由用户再次明确点击首页按钮建立。
