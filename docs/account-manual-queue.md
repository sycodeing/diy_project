## 独立手动助手

`x-lead-studio/run-account-manual.sh` 只启动 `lead_studio.account_manual_helper`，不导入 `lead_studio.app`、不启动自动 worker。它复用本地服务的后端认证配置，但不读 x-use Cookie、普通 Chrome Cookie 或其他浏览器资料。启动只注册新 boot、上报本机助手状态并轮询独立请求表；不会开浏览器、连代理、探测 IP 或访问 X。旧 boot 或超过两分钟的请求不执行，领取使用一次性 CAS。

只有用户点击明确的 IP 窗口请求后，助手才使用后台当前固定代理配置打开标准 Google Chrome 的独立持久资料目录，首次仅显示 IP 核对页。用户先人工核对页面显示的预期出口，再登记本次 IP 声明；确认绑定到当前 boot、session、账号、网络配置版本和预期 IP。新助手启动、窗口关闭或网络绑定变化都会使旧确认失效。

随后在后台复制目标链接，切回上述独立绑定窗口，在同一标签地址栏粘贴访问。登录、核对 X 当前账号、上传素材和发送均由用户亲手完成。助手不自动导航 X 或检测登录身份，不会从其他资料目录复制 Cookie。持久 Chrome 自行保留用户手动登录的正常浏览器状态；这不是临时 Cookie 克隆窗口。

同账号及绑定仍有效时，后续开窗请求只报告已有窗口，不刷新、不导航、不增加标签。窗口被用户关闭时不自动重建，需用户核对后显式重新启动助手。绑定变更会阻断复用并保留旧窗口和连接，不自动换 IP、回退直连或创建新会话。遇登录、安全验证、限制或账号不符应停止用户发送；助手不点击验证、不申诉、不自动重试。浏览器页面自身仍可能产生后台网络请求。

助手收到停止信号后停止接收新请求；若它拥有的用户窗口仍存在，会保留所需代理连接直到用户关闭该窗口，不会关闭其他浏览器。停止和安装本助手不改变原自动服务的停用状态。

## 数据迁移

数据库迁移仅创建隔离结构和保护函数，不自动移动业务数据。单独调用 `migrate_account_v2_to_manual` 时须传精确冻结的 18 个原任务及审计操作者；事务内锁定并核对 `queued / attempt_count=0 / 无领取或结果` 后，复制原文案、目标、追踪链接、原画和预览哈希，固定新手动账号，再把原任务标记为 rejected 并追加转人工原因。原账号、批准时间、计划时间和素材原样留在来源审计快照。任一源任务变化则整批回滚，重复调用不会重复新增。

V2 自动加入和批准入口已禁用，自动领取仅接收 V1。数据库还阻止 V2 再次进入 queued/claimed，并将手动队列纳入跨队列重复联系保护。上线或迁移不等于授权打开代理/X 窗口或实际发送。
